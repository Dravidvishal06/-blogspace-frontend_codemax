# BlogSpace Frontend

A responsive blog application built using React and Vite.

## Features

- Home Page
- Login Page
- Register Page
- Dashboard
- Create Blog Page
- React Router Navigation
- Reusable Components
- Responsive UI

## Tech Stack

- React.js
- Vite
- JavaScript
- CSS
- React Router DOM

## Installation

```bash
npm install
npm run dev
```
